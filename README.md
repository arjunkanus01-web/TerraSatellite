# TerraSatellite
i am making ISS tracker.it can search and find iss,calculate path display them on a 3d rotatable sphere and when satellites are passing it will automatically configure with the rtl to decode photo if it is weather satellite.i am using vs code.TERRA is a project I made using Python to create a 3D model of Earth. It has a realistic Earth texture, a blue atmospheric glow, and stars in the background to make it look like Earth in space. I used Plotly to make the globe rotatable and zoomable, and Skyfield with orbital data from CelesTrak to calculate the position and orbit of the ISS. I also turned the project into an interactive HTML page and published it using GitHub Pages, so people can view it in their browser. My goal is to keep improving TERRA and make it look and work more like a real space simulator.
